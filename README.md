# Ahmed Nasser · Data Analyst portfolio

Live: https://a7mdnasrr.github.io/AhmedNasser.github.io/

A single static page (`index.html` + `assets/site.css`, no build step, no frameworks). Light/dark theme, mobile-first.

- `images/` – avatar and project thumbnails (WebP, 800×500)
- `rmarkdown/` – knitted R Markdown reports (Cyclistic, Olist) linked from the project cards
- `.nojekyll` – serve the files as-is on GitHub Pages

To add a project, copy one `<article class="card">` block in `index.html`.
